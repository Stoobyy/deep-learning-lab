## The code in three parts

### 1) Import the dataset

```python
(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
x_train = x_train.reshape(-1, 28, 28, 1) / 255.0
x_test = x_test.reshape(-1, 28, 28, 1) / 255.0
```

- MNIST has 60,000 training images and 10,000 test images, each a 28×28 grayscale digit.
- **Difference from Day 3:** a DNN needs a flat row of 784 numbers, but a CNN needs the image **kept as 2D**. So we reshape to `(28, 28, 1)`: height, width, and **1 channel** (grayscale; a colour image would have 3).
- `/ 255.0` scales pixels from 0–255 to 0–1.

### 2) Build the CNN and train it

```python
layers.Input(shape=(28, 28, 1)),
layers.Conv2D(32, (3, 3), activation='relu'),
layers.MaxPooling2D((2, 2)),
layers.Conv2D(64, (3, 3), activation='relu'),
layers.MaxPooling2D((2, 2)),
layers.Flatten(),
layers.Dense(64, activation='relu'),
layers.Dense(10, activation='softmax')
```

| Layer | What it does | Output shape |
|---|---|---|
| `Input(28, 28, 1)` | One grayscale image | 28 × 28 × 1 |
| `Conv2D(32, (3,3))` | Slides **32 filters** of size 3×3 over the image. Each filter learns to detect a simple pattern (edges, lines) | 26 × 26 × 32 |
| `MaxPooling2D((2,2))` | Keeps the largest value in each 2×2 block. Halves the size and keeps the strongest features | 13 × 13 × 32 |
| `Conv2D(64, (3,3))` | 64 filters that combine the earlier edges into bigger shapes (curves, loops) | 11 × 11 × 64 |
| `MaxPooling2D((2,2))` | Halves the size again | 5 × 5 × 64 |
| `Flatten()` | Turns the 3D block into one long row so Dense layers can use it | 1600 |
| `Dense(64, relu)` | Fully connected layer that combines all features | 64 |
| `Dense(10, softmax)` | One output per digit, as probabilities that add up to 1 | 10 |

**Why the size shrinks after Conv2D:** a 3×3 filter can't be centred on the edge pixels, so 28 → 26 (28 − 3 + 1).

**Training:**

```python
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(x_train, y_train, epochs=5, validation_split=0.1)
```

- `adam` is the optimizer (updates the weights).
- `sparse_categorical_crossentropy` is the loss for multi-class problems where labels are plain integers 0–9.
- `validation_split=0.1` keeps 10% of the training data aside to check progress on unseen data.

**Evaluate accuracy:**

```python
loss, acc = model.evaluate(x_test, y_test)
```

Runs the trained model on the 10,000 test images and returns the loss and accuracy.

### 3) Print the confusion matrix

```python
y_pred = model.predict(x_test).argmax(axis=1)
print(confusion_matrix(y_test, y_pred))
```

- `argmax(axis=1)` picks the digit with the highest probability.
- 10×10 table: **rows = actual digit, columns = predicted digit.** The diagonal is correct predictions; anything off the diagonal is a mistake.

## Quick viva points

- **What is a filter (kernel)?** A small grid of weights (here 3×3) that slides over the image and responds strongly to one pattern.
- **What is a feature map?** The output of one filter over the whole image. It shows where that pattern appears.
- **Why pooling?** It shrinks the feature maps, reduces computation, and makes the model less sensitive to small shifts in the image.
- **Why does a CNN beat a DNN on images?** It keeps the 2D structure, so it learns local patterns, and the same filter is reused everywhere, so it needs far fewer weights.
- **Feature extraction process:** early conv layers detect simple edges; later layers combine them into shapes; the Dense layers use those shapes to decide the digit.
